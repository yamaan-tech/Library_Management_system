# Library Management System

## 1. Problem Statement

Managing books manually in a library can make it difficult to keep track of available books, issued books, members, and book records.

The Library Management System is developed to provide a simple computer-based solution for managing library books and members. The system allows the user to add, update, delete, search, issue, and return books.

The project also provides basic reports about total, available, and issued books.

## 2. Scope of the Project

The project focuses on basic library management activities.

The system covers:

* Book management
* Member management
* Book searching
* Book issue and return
* Book status management
* Basic library reports
* Data storage using JSON files
* Basic input validation
* Basic testing

The project is designed as a Python-based console application.

## 3. Target Users

The system can be used by:

* Small libraries
* College libraries
* School libraries
* Library staff
* Students for learning and demonstration purposes

## 4. High-Level Features

### Book Management

* Add a new book
* View all books
* Update book information
* Delete a book

### Member Management

* Add a library member
* View members
* Check duplicate member IDs

### Search

* Search books by title
* Search books by author
* Search books by category

### Issue and Return

* Issue an available book
* Return an issued book
* Check current book status

### Reports

* Display total number of books
* Display available books
* Display issued books
* Display category-wise book count

### Data Storage

Book and member information is stored using JSON files so that the data remains available after the program is closed.
